# VagasDash

Aplicação web desenvolvida em Python para organizar e acompanhar candidaturas a vagas de emprego, centralizando informações sobre empresas, cargos e etapas dos processos seletivos.

## Status do projeto

🚧 Em desenvolvimento.

O VagasDash está em sua fase inicial. As funcionalidades serão implementadas gradualmente ao longo do desenvolvimento.

## Objetivos

- Organizar candidaturas a vagas de emprego em um só lugar.
- Acompanhar o andamento dos processos seletivos.
- Facilitar a visualização das candidaturas e de seus respectivos prazos.
- Praticar e consolidar conhecimentos em desenvolvimento com Python.

## Tecnologias

- **Python** - linguagem de programação.
- **Streamlit** - desenvolvimento da interface web.
- **SQLite** - sistema de gerenciamento de banco de dados.

Outras tecnologias poderão ser adicionadas conforme o projeto evoluir.

## Funcionalidades

- [x] Estrutura inicial da aplicação web.
- [x] Configuração básica da página com Streamlit.
- [ ] Cadastro, edição e exclusão de candidaturas.
- [ ] Validação dos dados informados.
- [ ] Armazenamento persistente das candidaturas com SQLite.
